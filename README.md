# Nxt Trendz E-commerce

A responsive e-commerce web application built using React.js. Users can log in, browse products, search and filter products, view product details, and manage products in their shopping cart.

## Features

- User login authentication using JWT tokens
- Protected routes for authenticated users
- Browse and view products
- Search products using keywords
- Filter products by category and rating
- Sort products
- View detailed information about a selected product
- Add products to the shopping cart
- Increase or decrease product quantity
- Remove individual products from the cart
- Remove all products from the cart
- Update product price based on quantity
- Display total number of items in the cart
- Display total order amount
- Empty cart view when no products are available
- Responsive design for different screen sizes

## API Integration

The application integrates REST APIs to provide:

- User authentication
- Product listings
- Product search and filtering
- Product details
- Similar product recommendations

## Cart Management

The application uses React Context API to manage cart-related functionality:

- Add products to the cart
- Prevent duplicate cart items by updating product quantity
- Increase and decrease product quantity
- Remove individual cart items
- Remove all cart items
- Calculate total cart items
- Calculate total order amount
